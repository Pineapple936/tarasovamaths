# tarasovamaths.ru

**tarasovamaths.ru** — сайт, где можно познакомиться с курсами по математике, узнать больше о
преподавателе и легко записаться на занятия.

## О сайте

На сайте вы найдете:

-   📚 **Описание курсов** — подробная информация о программах, уровнях и темах занятий.
-   👩‍🏫 **О преподавателе** — опыт, достижения и подход к обучению.
-   📝 **Быстрая запись на занятия** — кнопка ведет напрямую в чат WhatsApp, чтобы согласовать время
    и детали.
-   🌐 **Удобный интерфейс** — адаптивный дизайн для компьютеров, планшетов и смартфонов.

## Почему стоит посетить

Сайт делает процесс выбора курса и записи максимально простым: достаточно изучить материалы и нажать
на кнопку записи. Нет сложных форм, регистраций или лишних шагов — всё для вашего удобства.

## 🛠 Технологии

-   [Next.js](https://nextjs.org/) (React Framework)
-   TypeScript
-   SCSS для стилей

## Заключение

**tarasovamaths.ru** — это удобный и современный способ познакомиться с курсами по математике и
начать обучение без лишних сложностей. Всё продумано для того, чтобы пользователю было просто,
понятно и приятно взаимодействовать с сайтом.
